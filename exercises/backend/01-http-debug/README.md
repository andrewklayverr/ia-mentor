# Exercício 02 — Depuração HTTP

**Tempo:** 20–25 minutos
**Objetivo:** diferenciar autenticação, autorização, validação e ausência de recurso.
**Concluído quando:** você classificar os cenários e justificar os status HTTP.

## Cenários

Para cada caso, escolha a resposta mais apropriada e explique:

1. Requisição sem credencial para uma rota protegida.
2. Credencial válida, mas usuário sem permissão administrativa.
3. Corpo JSON inválido para criar um usuário.
4. Usuário solicitado não existe.
5. Servidor lançou um erro inesperado no banco.

Depois, desenhe em pseudocódigo a ordem entre autenticação, autorização, validação e controller. Não peça a implementação completa antes de justificar a ordem.
