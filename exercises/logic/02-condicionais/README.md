# 02 — Classificação de acesso

Implemente `classificarAcesso({ autenticado, ativo, papel })`: sem autenticação → `nao_autenticado`; inativo → `conta_inativa`; ativo `admin` → `administrador`; ativo `user` → `usuario`; outro papel → `papel_invalido`.

Faça antes uma tabela de combinações. Teste: `npm run check:logic:2`.
