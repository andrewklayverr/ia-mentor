# 01 — Preço final

Implemente `calcularTotal(preco, descontoPercentual, frete)`. O desconto aplica-se ao preço e depois o frete é somado. Aceite apenas números finitos não negativos e desconto de 0 a 100. Erros devem usar `TypeError` ou `RangeError`.

Antes do código, simule `100, 15, 12`. Teste: `npm run check:logic:1`.
