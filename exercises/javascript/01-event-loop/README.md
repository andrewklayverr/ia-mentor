# Exercício 01 — Event loop

**Tempo:** 15–20 minutos
**Objetivo:** prever e explicar a ordem de código síncrono, microtasks e timers.
**Concluído quando:** a saída esperada estiver correta e a explicação não depender de decorar uma lista.

## Regras

1. Não execute o arquivo inicialmente.
2. Escreva sua previsão em `prediction.md`.
3. Explique o motivo de cada linha.
4. Só então execute `node challenge.js`.
5. Corrija sua explicação e crie uma variação própria.

O mentor deve usar a escada de ajuda do `AGENTS.md`.
