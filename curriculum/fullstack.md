# Trilha Fullstack adaptativa

A ordem não é uma playlist rígida. O mentor pode voltar a pré-requisitos ou antecipar aplicações, mas deve registrar o motivo.

## Fase 0 — Lógica e algoritmos (prioridade atual)

Siga `00-logica-algoritmos.md`. Não avance apenas porque o aluno já usou frameworks; aplique a prova de saída.

## Fase 0.5 — JavaScript do zero

Siga `01-javascript-do-zero.md` e valide cada unidade com fonte, execução, testes, explicação e variação.

## Diagnóstico prático

- decomposição de um problema;
- funções, arrays e objetos;
- assincronicidade;
- HTTP e API REST;
- SQL básico;
- Git e testes.

Saída: mapa inicial sustentado por evidências, não por autoavaliação. O diagnóstico adapta a prática, mas não presume domínio.

## Fase 1 — Fundamentos

- lógica e algoritmos;
- estruturas de dados essenciais;
- complexidade básica;
- terminal, processos e arquivos;
- Git;
- HTTP, DNS, JSON e cliente/servidor.

Projeto: CLI de tarefas com persistência em arquivo.

## Fase 2 — JavaScript e TypeScript

- escopo, closures e módulos;
- arrays, objetos e imutabilidade;
- event loop, promises e async/await;
- tratamento de erros;
- tipos, generics e narrowing;
- testes unitários.

Projeto: processador assíncrono com fila, retries e testes.

## Fase 3 — Backend

- Node.js e runtime;
- Express ou Fastify;
- rotas, middleware, controller e service;
- validação, erros e logs;
- autenticação e autorização;
- testes de integração.

Projeto: API de hábitos/estudos.

## Fase 4 — Dados

- modelagem relacional;
- SQL, joins, índices e transações;
- PostgreSQL;
- ORM e limites do ORM;
- migrações e consistência.

Projeto: persistir e consultar métricas da API.

## Fase 5 — Frontend

- HTML semântico e acessibilidade;
- CSS responsivo;
- DOM e formulários;
- React, estado, efeitos e composição;
- integração com APIs;
- testes de componentes.

Projeto: dashboard do sistema de estudos.

## Fase 6 — Fullstack e engenharia

- arquitetura em camadas;
- SOLID e padrões com moderação;
- segurança web;
- Docker;
- CI/CD;
- logs, métricas e observabilidade;
- fundamentos de cloud.

Projeto final: produto fullstack implantável, documentado e testado.

## Regra de avanço

Para avançar, o aluno deve aplicar sem copiar, explicar e resolver pelo menos uma variação. Lacunas não impedem todo progresso, mas entram na fila de revisão.
