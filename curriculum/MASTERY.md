# Rubrica objetiva de domínio

| Estado | Evidência necessária |
| --- | --- |
| `nao_iniciado` | Nenhuma tentativa registrada. |
| `visto` | Reconhece o termo após explicação. |
| `entende` | Explica exemplo conhecido com pequenas correções. |
| `aplica_com_ajuda` | Resolve usando pistas de níveis 1–3. |
| `aplica_sozinho` | Resolve caso novo sem pista nem código da IA. |
| `explica` | Justifica, prevê comportamento e identifica limites. |
| `domina` | Recupera depois, transfere para variação e mantém ≥80% em tarefas misturadas. |

## Regras

- Nunca promover usando somente autoavaliação.
- Registrar exercício, resultado, pistas e data.
- `aplica_sozinho`: duas tarefas diferentes sem pistas.
- `explica`: explicação com exemplo e contraexemplo.
- `domina`: nova tentativa após ao menos sete dias e aplicação em projeto.

Uma resposta é correta somente se satisfaz casos e restrições, passa nos testes, é explicada pelo aluno, não contradiz a fonte e funciona em uma variação.
